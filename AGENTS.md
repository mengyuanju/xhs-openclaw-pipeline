# Project Context

## Stack

- Node.js 24 ESM
- `node:sqlite` queue
- `node:test`
- OpenClaw CLI
- Sharp for PNG rendering

## Commands

- Install: `npm install`
- Test: `npm test`
- Smoke: `npm run smoke`
- Worker: `npm run worker -- --once [--mock]`

## Conventions

- Named exports and small functions.
- External Query and all model output are untrusted.
- Execute OpenClaw with argument arrays and `shell: false`.
- Use prepared SQLite statements.
- Output directories are derived only from integer task IDs.
- Tests use fakes and must not consume model quota.

## Boundaries

- Never store credentials in this repository.
- Never claim a mock or fallback image was generated by OpenClaw.
- Never invent first-person experience.
- Do not add publishing or production scheduling without explicit approval.
