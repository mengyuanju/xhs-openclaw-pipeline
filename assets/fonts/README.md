# Bundled standard Chinese font

`NotoSansSC-VF.ttf` is the unmodified Noto Sans SC variable font from the official Google Fonts repository, pinned to commit `2894aab31764f10f29c421bdfd2340d3b382d384`.

- Source: https://github.com/google/fonts/blob/2894aab31764f10f29c421bdfd2340d3b382d384/ofl/notosanssc/NotoSansSC%5Bwght%5D.ttf
- Original filename: `NotoSansSC[wght].ttf` (renamed only on disk)
- SHA-256: `a3041811a78c361b1de50f953c805e0244951c21c5bd412f7232ef0d899af0da`
- License: SIL Open Font License 1.1, included in `OFL-NotoSansSC.txt` with its copyright notice. The font may be bundled and redistributed with this software under that license.
- License source: https://github.com/google/fonts/blob/2894aab31764f10f29c421bdfd2340d3b382d384/ofl/notosanssc/OFL.txt

The text repair renderer verifies this exact font and its Unicode cmap before drawing. Do not substitute a system font or a remotely fetched fallback. The full font, rather than a Chinese-character subset, is included so supported phrases are consistently available on every executor.
