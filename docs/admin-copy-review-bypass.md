# 管理员免人工文案审核

管理员在工作台“创建笔记”中默认勾选“免人工文案审核，直接生图”。选项作用于本次批量创建的全部任务；取消勾选后继续人工审核。成功创建后，新批次恢复管理员默认勾选。普通用户与审核员不显示选项。

启用后的流程：创建任务 → 生成文案 → 自动放行并加入生图队列 → 人工归档。免审核只省略人工文案确认；现有文案格式要求、生图失败处理和图片审核继续生效。文案格式不完整时保存结果并进入待人工审核，进度说明原因。生图连续失败三次仍回到待人工审核，不会因免审核设置而无限重试。

## 接口与存储

`POST /v1/tasks` 新增批次级可选字段 `skipCopyReview: boolean`。接口默认 `false`，兼容旧调用；前端管理员默认提交 `true`。非管理员开启返回 `403`，非布尔值返回 `400`。身份沿用中心保存的当前角色和凭据版本校验，创建者取自认证上下文。

策略存入 `tasks.skip_copy_review`，不从任务 `input`、单条任务额外字段或模型结果读取。创建者仍记录在 `created_by_user_id`，策略在创建时确定。完成文案时，在同一数据库事务内保存文案版本、记录 `approval_mode = ADMIN_BYPASS`、批准时间与创建节点，并复用人工审核后的生图入队更新。过期、重复回调继续由执行锁拒绝；任一步失败整体回滚。

任务详情显示当前文案的“管理员免审核”记录；人工审核使用 `MANUAL`。历史已批准版本没有新字段时显示为人工审核。免审核使用任务原有的 AI 水印设置和默认图片配置。

## 启用

同时更新前端和中心服务代码。中心服务正常启动会自动执行新增迁移 `0012_skip_copy_review.sql`；已有任务默认 `false`，不会自动推进。无需修改旧迁移或手工改表。已经运行的中心服务需要重启以加载新逻辑与迁移；更新后刷新工作台。

本次验证只使用隔离环境，没有启动真实文案或图片生成，也没有修改运行中的业务数据库。
