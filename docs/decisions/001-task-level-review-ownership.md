# ADR-001: 生产质检采用任务级单一负责人

## Status

Accepted

## Date

2026-08-31

## Context

最初实现把 Query 和文案都建成独立质检工单。实际作业要求按内容条数分给不同质检人员，并且一条内容从文案到图片都由同一人负责。若继续按文案版本或图片版本派单，同一任务会产生多个负责人、重复统计条数，也难以界定最终责任。

## Decision

保留 Query 预审工单；生产质检新增 `task_id` 唯一的任务级分配。负责人不会因文案或图片版本变化而改变。文案和图片结论作为任务分配下的追加式阶段记录，分别绑定内容快照和哈希；图片结论还绑定当前文案哈希。

内部角色 `COPY_REVIEWER` 暂不改名，以兼容现有账号和会话，但 UI 统一显示“内容质检员（文案+图片）”。

## Alternatives Considered

### 继续按文案和图片分别建工单

- 优点：沿用现有工单表。
- 缺点：条数重复、责任人可能分裂、版本更新产生新工单。
- 结论：不符合单人贯穿负责的业务规则。

### 把整个任务做成一次性最终审核

- 优点：模型最简单。
- 缺点：图片生成前无法留下文案核对结论，也无法识别版本失效。
- 结论：不能表达真实的分阶段作业。

### 任务级负责人 + 阶段结论

- 优点：分配按任务计数，责任稳定；文案与图片证据仍可独立追溯。
- 缺点：需要新增表和受控图片读取接口。
- 结论：最符合当前作业方式，并为后续人工硬门禁留出边界。

## Consequences

- 管理员按批次、人员和条数精确分配未分配任务。
- 一个任务在任何时刻只有一个当前质检负责人。
- 文案或图片变化会使对应旧结论失效，但不会重新派人。
- 旧 COPY 工单仅保留兼容历史并迁入任务级记录；新 UI 不再生成它们。
- Worker 暂不等待人工结论；若后续增加硬门禁，只需消费任务级阶段状态，无需再次改变分配模型。
