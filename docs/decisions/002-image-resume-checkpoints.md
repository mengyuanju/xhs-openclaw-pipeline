# ADR-002：按原执行节点恢复生图检查点

状态：已实现，待部署。日期：2026-09-04。

## 背景

原分布式重试仅复用配置快照，会用新执行 ID 从视觉规划重新开始。生成、验收、质检、上传中的后续错误因此重复消耗前面已完成工作的模型额度。

## 决定

保留新执行 ID 和旧执行失效机制，在已有快照 JSON 中保存原节点及历史执行 ID。执行器按原文件和逐步结果恢复，中心让原节点领取恢复任务。图片 SHA-256 将检查结果和上传回执绑定到具体内容。

## 权衡

继续使用单个执行 ID 会削弱现有迟到结果隔离。将中间文件同步到中心可实现跨节点恢复，但需要增加中间素材协议、存储和传输，并超出当前修复范围。因此本次采用原节点本地检查点，不新增数据库表。

原节点离线时需要等待恢复，失败工作目录必须保留；节点磁盘丢失时无法恢复未上传文件。中心和执行器需要一起升级，Web 能力检查仅防止新界面误调用旧中心，不替代执行器版本升级。
