# 桌面整理三张图片完整提示词示例

本示例依据当前仓库的提示词文件与实际组装函数生成，包含封面、步骤页、清单页的完整请求，以及 Codex 图片工具执行要求。示例文案和画面数据为演示编写，不是历史任务记录，未调用模型或生成图片；示例正文仅用于图片事实核对，未作为正式文案提交，也未执行正式文案长度校验。后台已发布规则及任务冻结快照可能不同。

## 使用方式

每次生成一张图片。将对应页面的完整提示词作为任务输入，工具执行要求作为开发者指令。生成画布为 1152×1536，交付尺寸为 1086×1448，均为竖版 3:4。后续页可附首图作为风格参考，附件只能延续风格，不能复制首图内容。

合规标识在本示例中按当前程序契约由程序出图后叠加，模型不自行绘制。本示例不使用人物。仓库业务模板另有人像必须标识的规则，实际有人像任务应核对冻结配置与叠加逻辑。

## 工具执行要求

```text
Generate a brand-new PNG from the supplied text prompt. Any attached images are visual references only. Use $imagegen and the native image generation tool exactly once for one PNG, portrait 3:4. In the native tool's prompt, explicitly request a 1152x1536 pixel canvas (width x height), exact portrait 3:4, with all content composed within that canvas from the start. Preserve the full composition without cropping, stretching, rotation or padding. Any 1086x1448 delivery dimensions in the task describe downstream resizing by the application, not the native generation size. Save through the native tool. Do not synthesize images with code, download replacements, or use API keys. If the tool is unavailable, report failure. Return a JSON object with rawText describing the outcome.
```

## 第1张 封面

```text
<trusted_business_rules kind="IMAGE_SYSTEM">
根据上一步生成的标题和正文，为 桌面整理 生成第 1 张、共 3 张图文笔记图片。图片必须服务于用户的核心需求，并严格遵守以下规则。

## 内容与分页

- 图片必须严格对应标题和正文的内容、行文顺序与数据，关键核心信息必须完整覆盖；不得新增、篡改、错配或遗漏关键事实，也不得大段堆砌文字。
- 图片文字不得完全照搬正文，必须根据当前页信息适当简化和调整措辞，同时保持核心意思、数据和顺序一致。allowedVisibleText 是上游已经完成简化的最终可见文字白名单，生成时必须逐字呈现，不得再改写，也不得复制正文中的其他长段落。
- 相同信息焦点必须放在同一张图片中完整讲清，不得中途切断。推荐第一张同时呈现标题和核心结论，与正文的总—分—总结构一致；后续页面按正文顺序展开，末页可用于总结。
- 每套图片不得少于 2 张，通常优先生成 3～5 张，并严格按照运行时的 3 完成，不得缺页或多页。
- 单页信息量应与内容复杂度匹配；除非解释结论确有必要，不使用含大量文字的配图。可使用数据图表、关键词、对比表、步骤图和示意图提高信息效率。

## 尺寸、文字与可读性

- 生图时严格使用竖版 3:4、1152×1536 像素画布，完整内容在此画布内构图；程序后续等比缩小至 1086×1448 交付，不要求模型直接生成交付尺寸。不得横版、变形、裁掉边缘或添加白边。
- 禁止白色背景、深色背景和暗色背景，不使用大面积纯黑、深灰、深棕或接近白色的底色；选择明度适中的非白色背景，并让文字和背景保持清晰色差。
- 全页字体不超过 3 种；同一层级文字使用一致字体、字号与字重，优先使用手机端清晰可读的大字号。
- 严格使用中国大陆规范简体中文，不得出现繁体字。汉字、字母和数字笔画必须稳定完整，不得变形、乱码、缺笔、错位、拼音错误或不可辨认。
- 所有汉字和字母必须水平排列，禁止倾斜、波浪、弯曲或沿路径变形。横排、竖向信息流、环形布局和不规则排版仅指版块的位置关系，版块内文字仍须水平排版。
- 句子和标签保持精简，字距、行距和留白合理；物体和文字边缘清晰，图形轮廓稳定，不得模糊、颗粒化、涂抹或被裁切。
- 封面标题最多 2 行，标题文字区不超过画面高度的 24%；内页标题最多 2 行、标题文字区不超过画面高度的 16%，并明显小于核心实景、步骤或数据。内页禁止海报式满版大字、单字铺满、整页粗体和用大标题挤压正文；任何单个文字都不得成为占据画面主体的巨型字。

## 画面、风格与套图一致性

- 画面主体占据中心地位，关键主体、步骤或数据必须清晰可辨。遵循“字不压图”，画面干净、布局有序，不堆砌无意义元素或装饰。
- 优先采用真实风格，尤其是美食、旅游、攻略、操作步骤和实用教程；整体风格必须符合 Query 和品类调性。没有合适真实素材时可使用明确的 AI 示意场景，但不得冒充可核验的真实证据。
- 同一套图的冷暖色调、色系、光影、字体、装饰、图标和视觉语言保持一致；主色不超过 3 种，饱和度适中，配色和谐。
- 风格一致不等于排版重复。对于 3～5 张图的套图，至少 3 种不同的版式骨架必须被合理使用，并随内容在主视觉、左右分栏、上下分区、步骤动线、卡片清单、对比矩阵或局部特写中切换；不得连续复用相同的标题位置、主体位置和阅读动线。
- 套图中不得反复使用相同元素、底图、主体动作或配图，不得复制首图内容后只替换文字。多样性应来自不同步骤、角度、数据、场景和信息维度，而不是混用不相关风格。
- 一次处理多组图片时，必须依据各组文案内容使用不同模板和风格，不得让全部套图共用同一套版式。可按内容采用横排、竖向信息流、环形布局或不规则排版，但全部可见文字仍须水平排列。
- 涉及人像时，人物必须由 AI 生成，不得使用或仿冒未经授权的真实人物；必须在图片右下角清晰标注“AI生成”。标识不得遮挡主体或正文信息。
- 使用人物时禁止五官、肢体、手指、比例、透视、悬浮、穿模和阴影错误；其他实体、空间和操作步骤也不得违反基本结构或物理逻辑。

## 合规与交付

- 图片文字、数据、步骤和主体名称必须与正文一致，不得编造关键事实、错误知识、错误操作或正文之外的承诺。
- 禁止违法敏感、涉密、赌博诈骗、违禁品、色情擦边、血腥不适、恶趣味、不当价值观、谣言、数据造假、恶意抹黑、素人隐私和其他隐私信息。
- 禁止第三方水印、不一致 Logo、硬广、促销、二维码、联系方式、购买链接和站外引流。
- 禁止呈现可能造成人身、健康、重大财产或法律风险的错误知识和错误操作。
- 不得有明显通用模板痕迹；文字、图标和边框须精细，单页信息层级清楚，整体视觉舒适。

整套图片由图像模型一次性完成场景与文字排版，直接输出可交付的完整页面，不再由程序叠加第二层文字。必须逐字渲染 allowedVisibleText 中的 headline、subtitle、bullets、labels，以及运行时生产配置允许或人像规则强制要求的合规标识，不得增删、改写或添加其他文字；subtitle 为空字符串时不显示也不补写副标题。文字、卡片、图标、装饰和主体必须在同一视觉语言中自然融合，不得呈现后贴字幕、悬浮黑框或空白占位模板。最终文件继续执行 OCR 和图文语义验收；错字页只通过图像编辑修复。第一张确定整套主风格；后续图片引用第一张时，只延续色调、光影、字体、卡片、装饰和视觉符号，必须根据当前页信息生成全新场景与构图，不得复制首图内容或只换文字。
```
