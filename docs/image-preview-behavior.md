# 图片预览交互

任务审核中的图片共用一个预览弹窗。上下张切换只更新当前图片，不重新打开弹窗，也不重播遮罩和弹窗动画；当前显示模式、缩放倍数和观察底色在切换时保留。

图片区域和预览工具栏提供“默认完整预览”开关：开启后默认完整显示，关闭后默认按原始像素的 100% 显示。偏好保存在当前浏览器，多处开关同步；临时切换查看模式不会改写默认值。关闭重开或“恢复预览”会使用默认模式。浏览器禁止保存偏好时，当前会话仍可使用开关。

预览提前解码相邻图片。慢加载期间保留当前图片并显示所选图片的加载提示；加载失败可以重试，晚到的图片不会覆盖更新的选择。

观察底色、文件格式、背景处理、布局参数及历史图片版本均使用共用 Select 组件，支持键盘选择并保留禁用状态。对应的组件边界、导航状态和可访问性约束由 `npm test` 中的前端源码测试覆盖。
