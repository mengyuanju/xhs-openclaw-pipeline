# 图片预览交互

图片审核与任务图片批次共用一个预览弹窗。上下张切换只更新当前图片，不重新打开弹窗，也不重播遮罩和弹窗动画；当前显示模式、缩放倍数和观察底色在切换时保留。

图片区域和预览工具栏提供“默认完整预览”开关：开启后默认完整显示，关闭后默认按原始像素的 100% 显示。偏好保存在当前浏览器，多处开关同步；临时切换查看模式不会改写默认值。关闭重开或“恢复预览”会使用默认模式。浏览器禁止保存偏好时，当前会话仍可使用开关。

预览提前解码相邻图片。慢加载期间保留当前图片并显示所选图片的加载提示；加载失败可以重试，晚到的图片不会覆盖更新的选择。等待图片时禁止裁剪和 AI 编辑，防止对尚未看到的图片执行操作。旋转及未提交的编辑文字按图片重置。

观察底色、文件格式、背景处理、布局参数及历史图片版本均使用共用 Select 组件，支持键盘选择并保留禁用状态。

浏览器回归：`node scripts/test-image-preview.mjs`。脚本在 `.codex_artifacts/preview-regression` 复制实际组件、启动隔离页面并提供本地样例图片，不访问真实业务后端或模型。可通过 `PLAYWRIGHT_MODULE` 指定 Playwright 的入口，`PREVIEW_BROWSER_CHANNEL` 指定浏览器渠道；`--serve` 保留测试页面供人工检查。
