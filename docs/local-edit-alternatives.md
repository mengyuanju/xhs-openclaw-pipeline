# 历史局部修改的替代描述

2026-09-20 起，新局部修改直接使用原图和说明，不再生成视觉规划建议。图片编辑器的历史任务记录中，已识别目标但需要补充约束的局部修改，会显示三个可选描述：精准限定目标、自然修补或衔接、文字与边缘保护。删除请求对应“精准移除”和“自然修补背景”；移动请求对应“自然移动与衔接”。每个描述保留完整原始要求，不改变删除数量、移动方向或未点名内容。

这三个方向由已有规划结果和原说明组合生成，提供选项本身不新增模型调用。用户选择后可查看完整描述，点击“采用建议并修改”，操作原因预填为所选方案。结果仍需用户核验并采用。

历史 `LOCAL_EDIT_SUGGESTION` 和具有有效目标分析的 `LOCAL_TARGET_LOCALIZATION` 记录均可显示方案，无需数据库迁移。低置信度、服务异常、无效模型响应以及已有失败预览仍走原来的重试或定向修复流程。极长原说明继续使用“复用说明并修改”，避免追加约束时截断原意。

`apply-suggestion` 接口接收 `suggestionId`，中心根据当前版本的记录计算对应文本，不接受客户端提供的替代指令。选择后只保留实际提交的说明，并清除历史机器规划与蒙版，不再定位或检查选区；生成后仍做修改结果和文字验收。审计记录保存原说明、选中方案及实际提交文本，同一请求编号不能重复选择不同方案。

旧规划、移动几何及蒙版角色引导提示词已标为历史停用，保留历史版本查询兼容。上线需同步更新网页、中心和图片执行机；局部修改仅交给能力版本 9 的执行机。
