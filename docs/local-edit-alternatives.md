# 局部修改的替代描述

图片编辑器的任务记录中，已识别目标但需要补充约束的局部修改，会显示三个可选描述：精准限定目标、自然修补或衔接、文字与边缘保护。删除请求对应“精准移除”和“自然修补背景”；移动请求对应“自然移动与衔接”。每个描述保留完整原始要求，不改变删除数量、移动方向或未点名内容。

这三个方向由已有规划结果和原说明组合生成，提供选项本身不新增模型调用。用户选择后可查看完整描述，点击“采用建议并修改”，操作原因预填为所选方案。结果仍需用户核验并采用。

历史 `LOCAL_EDIT_SUGGESTION` 和具有有效目标分析的 `LOCAL_TARGET_LOCALIZATION` 记录均可显示方案，无需数据库迁移。低置信度、服务异常、无效模型响应以及已有失败预览仍走原来的重试或定向修复流程。极长原说明继续使用“复用说明并修改”，避免追加约束时截断原意。

`apply-suggestion` 接口接收 `suggestionId`，中心根据当前版本的记录计算对应文本，不接受客户端提供的替代指令。通过检查的建议沿用已确认规划；原先未通过规划检查的记录必须重新定位和检查范围，不会因选择方案而跳过检查。审计记录保存原说明、选中方案及实际提交文本，同一请求编号不能重复选择不同方案。

默认规划提示词同时明确：用户点名的多件对象可以是唯一目标集合；贴边或需要背景修补本身不等于无法修改。已有管理员发布的规划提示词仍优先使用，应按正常提示词发布流程同步这些规则。上线需同时更新网页和中心服务。
