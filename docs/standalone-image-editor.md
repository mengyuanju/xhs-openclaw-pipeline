# 独立图片编辑

入口 `/image-editor`，ADMIN 与 USER 可用。所有账号（包括 ADMIN）仅能查看和操作自己创建的工作区、参考图和结果；列表、详情、资产下载、提交和删除均在接口层校验创建人。与文案审核、质检和业务任务归属无关。

## 使用

上传 1–5 张 1086×1448 的 PNG/JPEG/WebP，每张原始文件最多 5 MiB。复用现有图片解码、签名检查、去 EXIF 与 PNG 规范化。不会自动裁剪或拉伸。默认限制集中在 `src/standalone-image-editor-config.mjs`，每个工作区冻结限制版本；未来调整尺寸必须同步坐标和处理器，当前不开放不受支持的尺寸设置。

页面仅展示图片编辑列表，右上角“新增图片”打开上传弹窗。选择图片后自动上传，上传成功后在同一弹窗下方立即展开编辑组件，无需再次打开编辑弹窗。点击“保存并提交生图”直接入队并返回列表；仅上传未提交的记录不出现在生图列表中。

上传后可添加人工生成标识（模型或程序）、替换产品、局部修改、取消、重试、对比、采用及恢复历史版本。成功或失败预览均保留原有验收标记。下载按钮仅在本轮生图结束且存在结果时显示，统一放在保存按钮左侧；原始上传和待生图、生图中不显示下载按钮。重新打开时恢复上次的标识文字、局部修改说明或产品替换参数，修改后保存会创建新请求，列表回到“待生图”。采用后可继续基于当前图片编辑。上传原图始终保留。

生图中的记录仅支持查看；参数输入、参考图上传、保存、恢复、采用、取消等修改操作均不可用。接口在编辑事务内持有与执行机领取相同的任务锁，再检查运行状态，避免打开旧弹窗绕过限制。多张图片保存使用同一个事务整体入队，任何一张校验失败都不会提交部分请求，执行机只能在整组提交后领取。

列表支持单条删除和勾选本页后批量删除。生图中不可删除；批量删除先校验全部记录的归属和运行状态，再原子执行。删除后记录、图片与编辑接口均不可访问，排队请求取消并暂停领取；底层资产和历史以删除审计标记保留，不物理清理文件。删除重试不会重复写入删除记录，不需要新增数据库迁移。

## 隔离与复用

原 `current-image-editor.tsx`、`image-editing.mjs`、`image-edit-renderer.mjs` 及原 CSS 未修改。新增编辑组件为独立副本，使用自己的接口命名空间；后端通过新增服务和处理器适配已有编辑引擎，原任务入口不接入新组件。

为兼容现有任务编号、资产外键和执行租约协议，工作区使用 `task_kind=STANDALONE_IMAGE_EDIT` 的内部任务作为执行载体。`standalone_image_workspaces` 记录不可变的上传账号、上传幂等键、哈希及默认限制。空的页面元数据只供旧执行协议使用，标记 `USER_UPLOAD`；没有生成或审核业务文案，也不对用户展示为已批准文案。

普通任务列表、个人列表及统计、作业模式、任务计数和重复 Query 扫描排除该类型。原业务任务接口拒绝操作这种内部记录，数据库约束禁止它进入普通生图、文案审核、图片审核或交付状态。采用结果仅切换独立工作区中的当前图片。

独立图片编辑仅在自己的列表查看状态，不再出现在原“生图中”页面。列表统一展示“待生图 / 生图中 / 已完成”；已结束的失败、取消和拒绝记录在已完成阶段下保留明确的结果说明及失败原因，可打开记录重试。列表自动刷新，保留分页和结果下载入口，后台通知跳转此入口。

## 执行

独立编辑仍进入现有 `image_edit_requests` 队列，共享 IMAGE 执行机、领取事务、负责人轮转、并发容量、租约续期和取消后的过期回传保护。执行机能力版本 **13** 才能领取独立编辑；旧执行机继续领取原任务，不能误领上传图。领取快照标记类型，只有独立编辑分派到新处理器。

新适配器根据原图与结果比较原有文字和未点名内容，不使用业务文案白名单。模型调用、冻结的管理员图片编辑提示词、标识/产品/局部操作和结果完整性校验仍由原引擎完成。假模型只在测试中注入。

## 部署与验证

应用 `0082_standalone_image_editor` 和 `0083_standalone_image_editor_compatibility_repair` 后更新并重启中心、网页和图片执行机。中心启动时会自动应用待执行迁移。

若数据库已执行早期 `0082`（尚未包含工作区状态约束），迁移器仅接受已知的精确校验值，并通过 `0083` 补齐约束；已执行完整 `0082` 和全新数据库也兼容。保留原迁移校验记录，不修改任务、图片或工作区数据；未知校验值仍阻止启动。没有自动应用生产迁移、发布或增加生产定时任务。

验证：`npm run typecheck`、`npm test`、`npm --prefix server test`；隔离数据库端到端测试设置 `RUN_POSTGRES_E2E=1` 后执行 `node --test server/tests/standalone-image-editor.test.mjs`；浏览器测试设置 `RUN_IMAGE_EDIT_BROWSER=1` 后执行 `node --test tests/standalone-image-editor-browser.test.mjs`。测试不消耗模型额度。

删除成功后会同步清理该工作区全部后台任务与提醒，跨标签页保留删除标记，避免旧轮询响应恢复通知。已删除编辑的状态查询只向创建人返回最小删除状态，不再当作生图失败；详情、图片和修改接口仍不可访问。旧版缓存中的不可用通知会在重新打开新版页面时复查并静默清理。
