# 任务详情与审核弹窗

文案审核阶段在桌面端采用左右双栏：左侧为原始 Query、标题、正文、标签及可折叠的资料来源，右侧为图片文案规划。两栏独立滚动；不足 1024px 时切换显示文案或图片规划，编辑内容保存在同一份草稿中。图片审核与已完成详情保留文案、图集、规划的查看顺序。人工归档阶段允许管理员修正现有页面的标题、副标题、要点和画面指令；页数与页面类型保持锁定。管理员完成本轮图片评分并选择“重试生图”后，中心以不可变方式新增一条人工批准文案修订版，保留旧文案版本和旧图集，再用新规划进入图片队列。

- 移除任务概览，Query 原文在文案区只读展示，长内容可展开；没有文案时仍显示 Query 和必要的失败提示。
- 图片规划提供页码、类型和标题摘要，默认展示第一页，生成指令默认折叠。
- 交付格式、背景、格式转换和历史配置恢复仅管理员可见。普通用户和审核员的文案提交保留任务已有图片配置。
- 文案、全部图片规划和水印选择沿用现有审核接口一起提交。机器原稿只有 `3` 分可不改文案直接确认；`2` 分或 `2.5` 分必须实际修改标题、正文或标签，确认达标后由系统把最终稿记录为 `3` 分，不再要求“修改后自评”。
- 提交按钮按实际去向说明：普通初审通过后可能先进入批次抽检；抽检或图文终审打回的返工稿使用“确认返工文案达标并提交强制复检”，不会显示或暗示立即开始生图。只有无需抽检、普通抽检完成或强制复检通过后，任务才进入待生图队列。
- 关闭或刷新前提示未提交修改；提交失败保留草稿。提交时校验所有页面，并展开、定位首个不合格字段。
- 生图重试耗尽返回文案审核时，保留失败提示及旧图片；旧图放在左栏，保持双栏布局。
