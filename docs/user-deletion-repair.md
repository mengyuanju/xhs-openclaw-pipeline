# 用户删除修复

日期：2026-09-29。

有图片初审、图片抽检、图文规划重生成或独立图片编辑历史的账号，在删除时会被历史账号外键阻止。原始数据库异常经中心服务映射为 `control plane request failed (INTERNAL_ERROR)`。现用正式库的只读检查确认这些约束及关联记录存在。

新增迁移 `0099_user_deletion_history`，将六类历史身份改为保留原数字账号 ID 的记录：图片初审、图片抽检冻结、抽检明细、抽检余数、图文规划重生成请求、独立图片工作区。删除用户后历史记录和图片资产继续保留；同名新账号不能继承旧工作区或请求。保留余数还允许已删除提交者的迟到尾批继续冻结。

独立图片上传使用固定 `MANUAL_ARCHIVE` 状态的协议任务，删除检查改为读取真实编辑请求。排队或运行中的编辑仍阻止删除；无后台生成工作的工作区可解除负责人并保留历史。普通未完成任务、当前登录账号及最后一位启用管理员继续受原有保护。删除事务按用户、任务、编辑顺序锁定，异常回滚任务与 Query 分配。
